# Curso em Vídeo - Python Exercises Solutions 🐍

This repository contains my **solutions and implementations** for the exercises proposed in the **Python 3 course** by [Curso em Vídeo](https://www.cursoemvideo.com/), taught by Professor **Gustavo Guanabara**.

The repository follows the progression of the course through its three modules ("Mundos"), covering topics from basic programming logic to control structures, data structures, functions, input validation, and problem-solving.

---

## 🎯 Repository Purpose

This repository was created to:

- Document my learning journey with Python.
- Practice programming logic and problem-solving.
- Organize the exercises completed throughout the course.
- Share my solutions as a reference for other students.
- Track my progress as I develop a stronger foundation in programming.

> This is primarily a learning repository and reflects my understanding of each exercise at the time it was implemented.

---

The repository documentation and most code comments are written in **English** to make the project easier to understand for a broader audience.
